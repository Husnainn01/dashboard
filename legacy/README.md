# Legacy Files

This directory contains files that were part of the original monolithic architecture but are no longer needed in the microservices architecture.

These files are kept for reference purposes and should not be used in the current implementation.

## Directory Structure

- `backend/main.py` - Original monolithic orchestrator
- `backend/services/` - Original service implementations
- `backend/signal_generator/` - Unused signal generator module
- `frontend/` - Legacy frontend components

## Note

If you need to restore any functionality from these files, please adapt it to the microservices architecture rather than reverting to the monolithic approach.
